# 게임 사양서

[프로젝트 문서](README.md) / 사양서 · [구현 현황](IMPLEMENTATION.md)

게임에서 유저가 할 수 있는 일과 그 결과를 세 문서에서 관리한다. **로비**에서 방어선을 정비하고, **인게임**에서 퍼즐 한 판을 플레이하며, **카드**마다 어떤 능력치를 갖고 어떻게 성장하는지는 카드 사양을 따른다.

|---|---|---|
| [로비 사양서](LOBBY-DEFENSE.md) | 게임에 들어가기 전후의 화면과 로비에서 진행 중인 방어 스테이지 | [탭과 주요 행동](LOBBY-DEFENSE.md#로비-화면과-탭), [전장 배치](LOBBY-DEFENSE.md#3-보드와-배치-규칙), [자동 전투와 경제](LOBBY-DEFENSE.md#4-자동-전투와-경제) |
| [인게임 사양서](INGAME-BATTLE.md) | 퍼즐 한 판의 입력·득점·종료와 배틀 승패 | [한 판의 진행](INGAME-BATTLE.md#한-판의-진행), [현재 승패와 기록](INGAME-BATTLE.md#현재-승패와-기록), [방어선 연동안](INGAME-BATTLE.md#방어선-연동안) |

## 영역이 만나는 지점

- **카드를 뽑고 배치할 때** 상점의 골드 비용과 배치 가능한 셀은 로비 사양을 따른다. 뽑힌 장의 보너스와 최종 공격·방어·체력은 카드 사양으로 계산한다.
- **플레이 버튼을 누를 때** 로비는 방어 진행을 저장하고 퍼즐로 진입한다. 이후 시간 제한, 상대 기록, 승패와 재도전은 인게임 사양을 따른다. 현재 90초 대전은 퍼즐 점수로 판정한다.
- **리그 기획**에서 배틀 집계·승급·시즌은 [인게임 사양서의 배틀 리그](INGAME-BATTLE.md#배틀-리그), 닉네임 옆 티어 표시와 갱신 시점은 [로비 사양서의 화면과 탭](LOBBY-DEFENSE.md#로비-화면과-탭)에서 다룬다.

기획 중인 규칙과 미정인 수치는 각 사양서에 표시한다. 기능별 작업 상태와 코드 근거는 [구현 현황](IMPLEMENTATION.md)에서 관리한다.
