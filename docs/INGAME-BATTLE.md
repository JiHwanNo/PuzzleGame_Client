# 인게임 사양서

[게임 사양서](SPEC.md) / 인게임 · [인게임 구현 현황](IMPLEMENTATION.md#인게임)

메인 배틀은 같은 규칙·스테이지·시드에서 90초 동안 플레이한 퍼즐 점수를 겨루는 비동기 대전이다. 현재 클라이언트는 로컬에 저장된 완주 기록을 상대 보드에서 재생한다. [로비 방어 스테이지](LOBBY-DEFENSE.md)와 [카드 수집·강화](LOBBY-CARDS.md)는 각각의 로비 사양에서 다룬다.

## 한 판의 진행

| 시점 | 현재 플레이 경험 |
|---|---|
| 진입 | 로비의 플레이 버튼을 누르면 최신 호환 대전 기록을 찾는다. 준비 팝업에서 규칙을 추첨해 진입한 경우에는 해당 규칙의 기록 중에서 고른다. 준비에 성공하면 라이프 1개를 소모하고 게임 씬을 연다. |
| 첫 기록 | 호환되는 완주 기록이 없으면 혼자 90초를 플레이해 첫 기록을 남긴다. 로비에서 규칙 지정 없이 바로 시작한 첫 판은 탭 매치다. |
| 상대가 있는 판 | 플레이어가 내 보드를 조작하는 동안 우측 상단의 작은 보드에서 상대의 입력을 재생한다. 양쪽은 같은 초기 조건에서 시작하며 각자의 입력으로 점수를 얻는다. |
| 종료 | 초당 50틱으로 4,500틱을 진행한다. 도중에 스테이지 목표를 달성해도 배틀은 90초까지 이어진다. |
| 결과와 복귀 | 최종 점수와 판정 결과를 표시하고 내 기록을 저장한다. 결과 화면에서 같은 시드·상대로 다시 도전하거나 로비로 돌아간다. 저장 실패는 결과 화면에 표시한다. |

## 퍼즐 조작과 득점

아래 세 조작 방식은 배틀과 개별 퍼즐 스테이지에 쓰인다. 배틀은 시간 만료 후 점수를 비교하고, 개별 스테이지는 설정된 목표를 모두 달성하거나 해당 규칙의 제한 시간이 끝나면 종료한다. 스테이지의 시간 제한이 0이면 무제한이다. [스테이지와 규칙 데이터](RULES-AND-STAGES.md)

| 규칙 | 한 번의 유저 매칭 성공 |
|---|---|
| 3매치 | 인접 블럭을 교환해 같은 종류를 한 줄에 3개 이상 맞춘다. 교환으로 처음 성립한 매칭을 한 번 센다. |
| 링크 | 같은 종류의 인접 블럭을 3개 이상 이어 손을 뗀다. |
| 탭 매치 | 서로 연결된 같은 색 블럭 2개 이상의 묶음을 터뜨린다. |

블럭을 파괴하면 점수가 오른다. 유저 매칭에 연속으로 성공하면 콤보가 쌓이고, 7콤보에 도달하면 7초 동안 피버의 2배 점수 배율이 적용된다. 자동 연쇄와 폭탄 파괴도 득점에 포함되지만 별도 유저 매칭으로 세지는 않는다. [점수와 콤보 계산](INGAME.md#점수-및-콤보-objectivemanager)

폭탄 블럭이 파괴되면 원형 반경 2칸 안의 블럭에 파괴가 이어진다. 스테이지 목표는 점수 획득과 지정 블럭 수집을 지원한다. 줄 제거형 특수 블럭은 추가 후보이며 발동 조건과 범위는 미정이다.

배틀 전용 **피벗**은 파괴한 블럭으로 게이지를 채우면 발동한다. 활성 중에는 원래 매칭 주변 한 겹도 파괴한다. 링크는 육각형 이웃, 3매치와 탭 매치는 상하좌우 이웃이 대상이다. 추가 파괴는 일반 득점 규칙을 따르고, 빠른 연속 매칭은 피벗의 유지에 기여한다. [피벗 효과와 재생 규칙](INGAME-VIEW-AND-BATTLE.md#대전-전용-피벗-모드)

세 퍼즐 규칙의 초기 밸런스에서 블럭 한 개는 기본 4점 충전된다. 콤보 보너스가 없으면 75개로 300점에 도달한다. 10콤보에는 블럭당 4.4점, 20콤보에는 4.8점이다. 매초 매칭 한 번으로 10개씩 파괴하면 8초에 발동하고, 이후에도 1초 이내로 계속 성공하면 게이지 회복으로 제한 시간까지 지속할 수 있다.

## 현재 승패와 기록

| 종료 시점의 상태 | 판정 |
|---|---|
| 호환 상대 기록을 정상 재생 | 양쪽 최종 퍼즐 점수를 비교한다. 내 점수가 높으면 승리, 낮으면 패배, 같으면 무승부다. |
| 첫 기록 도전 | 튜토리얼 종료와 내 점수를 표시한다. 이 판의 완주 기록은 이후 대전 상대 후보가 된다. |
| 상대 기록 재생 실패·종료 틱 또는 점수 불일치 | 내 점수와 상대 기록 확인 실패를 표시하고 해당 판의 승패 비교를 제외한다. |

양쪽은 동일한 규칙 버전과 피벗 설정으로 점수를 계산한다. 과거 60초 기록은 당시 길이로 재생할 수 있으며 현재 90초 대전 상대는 호환되는 90초 완주 기록에서 고른다. 서버 랭킹은 별도 기획이다. [리플레이와 대전 구현](INGAME-VIEW-AND-BATTLE.md#스테이지와-90초-대전)

## 배틀 리그

**기획 단계.** 배틀을 플레이하는 동안 리그를 상시 운영하고 결과를 티어에 반영한다. 서버에서 상대 기록을 배포하고 종료 점수를 랭킹 점수로 환산·집계하는 방안이 있다. 현재 게임은 로컬 기록으로 한 판의 승패를 표시하는 단계다. 로비에서 티어를 확인하는 위치는 [로비 화면과 탭](LOBBY-DEFENSE.md#로비-화면과-탭)을 따른다.

| 결정할 항목 | 정해야 할 규칙 |
|---|---|
| 집계 대상 | 첫 기록 튜토리얼, 중도 종료, 같은 상대 재도전을 리그에 어떻게 반영하는가? |
| 티어 | 티어의 이름과 개수, 최초 배치 기준, 경기 결과에 따른 승급·강등 조건은 무엇인가? |
| 시즌 | 시즌을 구분하는가? 구분한다면 시즌 경계에 걸친 경기는 어느 시즌에 집계하는가? |

## 방어선 연동안

아래는 로비 기획서에서 옮긴 **미구현 연동안**이다. 현재 배틀의 승패는 위의 퍼즐 점수 비교로 결정한다.

1. **시작 배치.** 각 유저의 로비 전장 20열 × 10행 전체를 경기 시작 시점에 복사한다. 각자의 유닛·트랩 위치, 합산 능력치, 트랩 효과와 입구·출구를 보존하며 경기 중 유저의 재배치는 잠긴다. 시작할 때 입구에서 출구까지 통행할 수 있는지 확인한다.
2. **점수 몬스터 소환.** 내가 얻은 블럭 점수는 상대 방어선에, 상대가 얻은 블럭 점수는 내 방어선에 몬스터를 보낸다. 소환량 계산에는 블럭 점수만 사용해 처치 가점으로 소환이 반복되는 일을 막는 방안이다.
3. **전투와 득점.** 몬스터는 왼쪽 입구에서 오른쪽 출구로 향한다. 유닛이 경로에서 자동 공격하고 트랩은 발동한 자리에서 재충전된다. 블럭 점수에 몬스터 한 마리당 처치 가점을 한 번 더하는 안이다. 통행 확인용 등불유령은 처치·출구 점수 집계에서 제외한다.
4. **결과와 재현.** 결과에서 양쪽의 블럭 점수와 처치 점수를 구분해 보여준다. 상대의 입력을 논리 틱 순서로 재생하고 경기 시작 당시의 양쪽 배치·능력치·경로 결정 규칙을 사용해 몬스터의 소환과 방어 결과를 재현한다. 경기 후 로비에서 카드나 배치를 바꿔도 지난 경기 점수는 유지돼야 한다.

기존 피드백 제안은 몬스터가 지나간 길에서 공격 범위가 겹치거나 비었던 구간을 보여주고, 유저가 복귀 후 다음 대전의 방어선을 손볼 수 있게 하는 것이다. 점수 몬스터의 골드·성장 재료 지급도 별도 보상 제안이다.

### 연동 전에 결정할 규칙

- 블럭 점수가 기준을 넘을 때마다 소환할지, 일정 시간 동안의 점수를 모아 웨이브로 보낼지 결정한다. 점수 환산 단위와 몬스터 종류별 처치 점수도 함께 정한다.
- 일반 몬스터가 출구에 도달할 수 있는지, 도달 시 감점을 적용할지, 총점의 하한을 둘지 정한다. 연동 후 합산 점수가 같을 때의 판정과 제한 시간에 남아 있는 몬스터 처리도 미정이다.
- 빈 전장과 우회로에서 첫 소환 시각, 실제 이동 시간, 종료 시 생존 수를 측정해 대전용 이동 속도를 정한다. 예를 들어 빈 전장의 19걸음은 초당 한 칸일 때 19초다.
- 서로 다른 배치 두 개로 경기 중 재배치 잠금, 등불유령 출구 통과 시 점수 변화 0, 같은 기록 재생 시 동일한 처치 수·최종 점수를 검증한다. 로비 자리 비움 수익은 로비에서 별도로 정산한다.

구현 상태와 담당 클래스는 [인게임 구현 현황](IMPLEMENTATION.md#인게임)에서 확인한다.
