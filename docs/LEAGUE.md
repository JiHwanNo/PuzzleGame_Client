# 배틀 리그 사양 초안

**기획 단계.** 배틀을 플레이하는 동안 리그를 상시 운영하고 결과를 티어에 반영한다. 서버에서 상대 기록을 배포하고 종료 점수를 랭킹 점수로 환산·집계하는 방안이 있다. 현재 게임은 로컬 기록으로 한 판의 승패를 표시하는 단계다. 로비 왼쪽 위 프로필에 닉네임과 현재 리그 티어를 함께 표시할 예정이다. 현재 프로필은 닉네임과 첫 글자를 표시한다.

| 결정할 항목 | 정해야 할 규칙 |
|---|---|
| 집계 대상 | 첫 기록 튜토리얼, 중도 종료, 같은 상대 재도전을 리그에 어떻게 반영하는가? |
| 티어 | 티어의 이름과 개수, 최초 배치 기준, 경기 결과에 따른 승급·강등 조건은 무엇인가? |
| 시즌 | 시즌을 구분하는가? 구분한다면 시즌 경계에 걸친 경기는 어느 시즌에 집계하는가? |
| 프로필 표시 | 첫 배치 전과 집계 중에 무엇을 표시하고, 경기 후 어느 시점에 티어를 갱신하는가? |
