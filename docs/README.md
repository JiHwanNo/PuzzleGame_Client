# 개발 문서

처음 프로젝트를 열었다면 [프로젝트 개요와 실행 흐름](../README.md)을 읽으세요. 기능을 수정할 때는 [작업별 빠른 경로](MAP.md#작업별-빠른-경로)에서 시작 파일을 찾은 뒤, 연결된 영역 문서의 **콘텐츠와 C# 매핑** 표에서 관련 타입과 메서드를 확인하세요.

- 설계 의도와 런타임 흐름은 [아키텍처](ARCHITECTURE.md)에 정리되어 있습니다.
- 아웃게임 전투는 [로비 디펜스 개발 기획서](LOBBY-DEFENSE.md), 카드의 별·분해 에너지·개별 강화는 [방어 카드 수집과 강화 사양](LOBBY-CARDS.md)에서 확인하세요.
- 배틀 중 상시 리그와 로비 프로필의 티어 표시는 [리그 사양 초안](LEAGUE.md)에서 확인하세요.
- 영역별 문서와 디버깅 경로는 [문서 지도](MAP.md)에 있습니다.
- 화면별 색과 글자, 공용 UI 리소스, 블럭과 슬롯 릴의 그림 기준은 [게임 UI와 퍼즐 아트 스타일](ART-STYLE.md)에서 확인하세요.
- 작업 규칙은 [AGENTS.md](../AGENTS.md), 커밋 전 확인 항목은 [코드 리뷰 체크리스트](CONVENTIONS.md)를 따릅니다.
- 과거 변경 배경은 [변경 이력](CHANGELOG.md)에서 확인하세요.
