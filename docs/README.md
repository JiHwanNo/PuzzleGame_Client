# 프로젝트 문서

## 1. 사양서

플레이 규칙과 기획 중인 기능은 [게임 사양서](SPEC.md)에서 확인한다.

| 하위 문서 | 다루는 내용 |
|---|---|
| [로비 사양서](LOBBY-DEFENSE.md) | 탭, 프로필·재화, 방어선 배치, 스테이지 진행과 복귀 |
| [인게임 사양서](INGAME-BATTLE.md) | 퍼즐 조작, 한 판의 시간·득점·승패, 배틀 리그와 방어선 연동안 |
| [카드 사양서](LOBBY-CARDS.md) | 종류와 보유 카드, 별 등급, 뽑기 보너스, 분해 에너지와 강화 |

## 2. 구현 현황

[구현 현황](IMPLEMENTATION.md)은 로비·인게임·카드별로 구현·부분 구현·기획 상태와 현재 코드 위치를 기록한다. 기능을 수정할 때는 [코드 지도](MAP.md), 화면의 실제 아이콘과 원화는 [스타일 가이드](ART-STYLE.md), 이전 변경 근거는 [변경 이력](CHANGELOG.md)에서 확인한다.

실행 방법은 [프로젝트 README](../README.md), 작업 규칙은 [AGENTS.md](../AGENTS.md)와 [코드 리뷰 체크리스트](CONVENTIONS.md)에 있다.
