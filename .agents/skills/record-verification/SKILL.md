# 검증 화면 녹화

1. 사용자가 확인하려는 조작과 화면에서 관찰할 결과를 정한다. 대상 창이나 뷰에 녹화를 맞추고, 조작 전 상태부터 결과가 읽히는 순간까지 담는다. 터미널 작업이면 실행 명령과 판정 결과가 보이는 터미널을 담는다.
2. 대상 환경에서 가능한 캡처 방식을 사용한다. Unity에서는 Game View 또는 실제 씬을 렌더링한 프레임을 MediaEncoder로 기록할 수 있다. 웹과 데스크톱 앱은 해당 창을 녹화한다. 중간 영상이 WebM 등이면 실제로 MP4로 인코딩한다. 캡처 중간 파일은 임시 작업 폴더에 둔다.
3. 인코더를 닫은 다음 MP4를 재생하거나 디코딩한다. 재생 시간이 0보다 크고, 조작 전후 프레임에 대상 화면과 판정 근거가 보이는지 확인한다. 검증 실패를 보여 달라는 요청도 실제 실패 장면을 그대로 담는다. 재현·녹화에 실패하면 막힌 지점을 알린다.
4. 확인한 MP4를 [저장 스크립트](scripts/Save-Recording.ps1)에 전달한다. 실제 Windows 바탕화면 위치를 조회해 `녹화` 폴더를 생성하고 날짜와 장면 이름을 붙여 저장한다. 현재 요청에 대한 기존 녹화가 있으면 내용과 버전을 확인한 뒤 재사용할 수 있다.

```powershell
& ./.agents/skills/record-verification/scripts/Save-Recording.ps1 -Source $verifiedMp4 -Title '로비 방패병 배치'
```

응답에는 스크립트가 반환한 절대 경로로 MP4 링크를 제공하고, 확인할 장면이나 시점을 짧게 적는다. 자동 입력·배속·편집기 재현을 사용한 경우 실제 녹화 조건을 함께 밝힌다.
