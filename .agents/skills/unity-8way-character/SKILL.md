# 원화에서 Unity 8방향 캐릭터 만들기

입력은 캐릭터 원화 또는 프로젝트 안의 원화 경로다. 첨부·지정된 원화를 먼저 열어 확인한다. 원화를 찾을 수 없으면 파일이나 위치를 요청한다. 한 장의 완성 그림도 입력으로 받으며 파츠 분리와 보이지 않는 방향의 보완은 제작 과정에 포함한다.

## 파츠와 방향

1. 원화에서 얼굴, 실루엣, 비대칭 장식, 장비를 든 손, 색상과 비율을 기록한다. 앞모습만 주어진 경우 뒤쪽의 추정 요소를 일관되게 설계한다. 방향 시트를 새로 그릴 때도 원화를 참조한다.
2. S·SE·E·NE·N·NW·W·SW를 각각 준비한다. S는 화면 아래쪽을 바라보는 정면이다. 발바닥과 몸통 기준점, 방향별 렌더 순서를 먼저 맞춘다. 걷기에 필요한 좌우 다리 또는 해당 캐릭터의 이동 기관을 분리하고, 관절 아래에 가려지는 영역을 채운다.
3. Canvas의 캐릭터 루트 아래에 RectTransform 관절을 배치한다. 몸통·머리·팔다리·장비·꼬리 등 실제 원화에 맞춰 자식 관계와 피벗을 정한다. 무기 없는 캐릭터도 그 원화의 자세와 능력으로 구성한다. 방향을 바꿀 때는 한 방향만 활성화한다.

## 네 가지 동작

| 클립 | 제작 기준 | 종료 |
|---|---|---|
| Idle · 대기 | 무게중심, 호흡, 시선 또는 보조 파츠가 서로 조금 다른 시점에 움직인다. | 자연스럽게 반복 |
| Attack · 공격 | 예비 자세, 해당 방향을 향한 타격, 회수를 만든다. 타격 순간 실루엣을 확인한다. | 같은 방향 대기 |
| Walk · 걷기 | 접지 → 체중 이동 → 반대쪽 접지를 한 주기로 만든다. 몸이 뜨는 캐릭터는 원화에 맞는 이동 주기를 쓴다. 이동 거리는 게임이 제어하고 클립은 제자리에서 반복한다. | 자연스럽게 반복 |
| Special · 스페셜 | 캐릭터 고유 능력에 맞게 예고, 발동, 여운의 자세를 새로 만든다. 능력이 지정되지 않으면 원화에서 읽히는 특징으로 한 가지를 정해 설명한다. | 같은 방향 대기 |

- 방향별로 네 동작을 키잉해 총 32개를 만든다. 기존 프로젝트의 클립·컨트롤러 제작 흐름을 활용한다. 새로 구성할 때는 [편집기 베이커](assets/DirectionalClips.cs.template)를 캐릭터 전용 Editor 스크립트로 복사해 클래스명을 정하고 호출할 수 있다.
- 베이커 입력은 이미 배치된 리그의 방향 루트 8개(루트 바로 아래, 나침반 이름), 기존 쓰기 가능한 출력 폴더, 클립마다 다른 커브를 기록하는 콜백이다. 콜백에서 발바닥·어깨·손목 등 실제 바인딩 경로와 원화 치수로 이동·회전 키를 넣는다. 편집기는 방향 표시, 반복 및 복귀, 컨트롤러 생성을 담당한다. 반환된 컨트롤러를 루트 Animator에 연결하고 프리팹을 저장한다.
- 키 데이터 하나를 원본으로 사용해 방향과 네 동작을 고를 수 있는 미리보기를 제공한다. 프로젝트 밖에서 검토할 때는 같은 파츠·피벗·레이어 순서와 시간을 반영한 HTML 등을 쓸 수 있다. 게임 판정은 기존 게임 로직에서 유지한다.

## 검증

8×4 조합을 재생해 방향별 실루엣, 가려짐, 발 미끄러짐, 무기나 이펙트 잘림을 확인한다. 대기·걷기의 시작/끝과 공격·스페셜 종료 후 방향 유지도 확인한다. 결과물에는 원화에서 추정한 부분, 미리보기 위치, 프리팹·클립 접근 방법과 Unity에서 실제로 확인한 범위를 적는다.
